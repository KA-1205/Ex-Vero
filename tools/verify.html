Verify an Ex-Vero evidence packet

An evidence packet is a self-contained, reproducible record of how one fact's conflicting reports folded into a single verdict. It carries the event log, the fold parameters, the derived trust, the fold output, a SHA-256 of the exact fold code, and a canonical-JSON hash sealing all of it.

1. Fetch a packet

curl -s "$GATEWAY/evidence/zone_c_gas" > packet.json

2. Verify it

python tools/verify_packet.py packet.json
# or straight from the hub:
curl -s "$GATEWAY/evidence/zone_c_gas" | python tools/verify_packet.py -

The verifier runs four independent checks:

  • SEAL — recomputes the canonical-JSON hash; any changed byte, dropped event, or nudged parameter is detected.
  • FOLD — re-runs the pure fold on the packet's own events and confirms the verdict matches exactly.
  • MODULE — compares the packet's fold-code SHA-256 to your local consensus_fold.py.
  • SIGN — if an admin secret is available, verifies the HMAC signature.

What this proves — and what it does not.

A verified packet proves the verdict is a faithful function of the recorded events. It does not prove the events themselves are true.

A bare hash detects accidental change only. It does not prevent whoever produced the packet from forging a consistent one. Use the HMAC signature (present when the hub has admin keys) to detect forgery.
